# Employee Leave Management System

## Description
A RESTful web application developed using Java and Spring Boot to manage employee leave applications. It uses an in-memory ArrayList for storing leave application details.

## Features
- Apply for employee leave.
- View all leave applications.
- Find leave applications by ID.
- Update leave application details.
- Delete leave applications.
- Validate employee name.
- Validate leave type.
- Validate number of leave days.
- Global exception handling.
- AOP logging for service methods.

## Technologies Used
- Java 17
- Spring Boot 3.5.7
- Spring Web
- Spring Validation
- Spring AOP
- Lombok
- Maven
- Postman

## Storage
In-memory ArrayList. No database required.

## How to Run
1. Clone or download the repository.
2. Open the project in IntelliJ IDEA.
3. Reload Maven dependencies.
4. Run `EmployeeLeaveManagementApplication.java`.
5. Test the REST APIs using Postman.
